## 9. Running the Application

1. Set the required CognoDB environment variables:
   - COGNODB_URI
   - COGNODB_USERNAME
   - COGNODB_PASSWORD

2. Open the project in Eclipse.

3. Run:
   `SkillMatchApplication.java`
   using **Run As → Spring Boot App**.

4. Wait until the console shows:
   `Started SkillMatchApplication`

5. Open the web application:
   `http://localhost:8788/index.html`

6. Enter a user email from the seed data and click **Find Matches**.
